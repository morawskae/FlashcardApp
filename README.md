# Flashcard App

A REST API for a flashcard learning platform built with **Python, Django, and Django REST Framework**. The application supports deck and flashcard management, token authentication, user-specific learning progress, public/shared decks, bookmarks, tags, search and filtering, learning statistics, and **SM-2 spaced repetition** for intelligent review scheduling.

The API is designed as the backend foundation for a future web or mobile learning application.
